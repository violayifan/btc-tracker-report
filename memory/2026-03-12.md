## 定时任务管理优化

### 用户请求
"优化定时任务管理"

### 问题诊断
1. 重复执行：BTC 任务有 2 个每小时任务（`auto_update.sh` + `update_btc_report.sh`），资源浪费
2. 缺乏监控：没有任务执行统计和健康检查
3. 日志分散：日志文件分散在不同位置，难以查看
4. 错误处理：缺乏失败重试和错误告警机制

### 优化方案

#### 1. 统一任务管理器
**文件**: `task_manager.sh`

**功能**:
- 统一的任务调度接口
- 自动重试机制（可配置）
- 任务执行统计（JSON 格式）
- 完整的日志记录
- 健康检查（Git、文件、磁盘、依赖）
- 日志清理（自动清理 7 天前日志）

**可用命令**:
```bash
./task_manager.sh btc     # 执行 BTC 完整流水线
./task_manager.sh arxiv   # 执行 Arxiv 论文日报
./task_manager.sh health  # 健康检查
./task_manager.sh stats   # 显示任务统计
./task_manager.sh cleanup # 清理旧日志
```

#### 2. 优化的定时任务配置
**文件**: `NEW_CRONTAB.txt`

```bash
# BTC 完整流水线（每小时）
0 * * * * /root/.openclaw/workspace/task_manager.sh btc >> logs/btc_pipeline.log 2>&1

# Arxiv 论文日报（每天 8:00）
0 8 * * * /root/.openclaw/workspace/task_manager.sh arxiv >> logs/arxiv_daily.log 2>&1

# 任务健康检查（每天 9:00）← 新增
0 9 * * * /root/.openclaw/workspace/task_manager.sh health >> logs/health_check.log 2>&1

# 日志清理（每周日 3:00）← 新增
0 3 * * 0 /root/.openclaw/workspace/task_manager.sh cleanup >> logs/cleanup.log 2>&1
```

**优化效果**:
- BTC 任务从 2 个减少到 1 个（节省 50% 资源）
- 新增每日健康检查
- 新增每周日日志清理
- 统一的日志目录结构

#### 3. 安全迁移脚本
**文件**: `migrate_crontab.sh`

**功能**:
- 自动备份当前配置
- 显示变更内容
- 用户确认后应用
- 验证新配置
- 提供回滚说明
