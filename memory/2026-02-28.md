## High-Frequency Futures Data Research

User interest: China commodity futures high-frequency data

### Key Findings:
1. **Tick-by-tick data is available** from China commodity futures exchanges
2. **CTP (综合交易平台)** provides official API for:
   - Tick-by-tick order data (逐笔委托)
   - Tick-by-tick execution data (逐笔成交)
   - Millisecond-level real-time push

3. **Exchanges providing this data:**
   - SHFE (Shanghai Futures Exchange): Gold, Silver, Copper, Aluminum, Zinc, Lead, Nickel, Tin, Rebar, etc.
   - DCE (Dalian Commodity Exchange): Corn, Soybeans, Meal, Oil, Palm Oil, PVC, PP, LLDPE, Coke, etc.
   - CZCE (Zhengzhou Commodity Exchange): Wheat, Cotton, Sugar, PTA, Methanol, Glass, etc.
   - INE (Shanghai International Energy Exchange): Crude oil, Natural rubber, etc.
   - GFEX (Guangzhou Futures Exchange): Industrial silicon, Lithium carbonate

### Data Access Methods:
1. **CTP MD Interface** (official, free for users with trading accounts)
2. **Commercial providers**: Wind, iFind, Bloomberg, Reuters (paid)
3. **Quantitative platforms**: VNPY (open-source, supports CTP)

### Reference:
- VNPY documentation: https://www.vnpy.com/docs/cn/community/info/gateway.html
- CTP API provides OnRtnOrder (order flow) and OnRtnTrade (execution flow)
- Level-2 data includes 5-level order book depth

### Technical Details:
- Data format: CThostFtdcDepthMarketDataField for market data
- Order flow: OnRtnOrder with OrderRef, Direction, LimitPrice, VolumeTotalOriginal
- Execution flow: OnRtnTrade with TradeID, Direction, Price, Volume, TradeTime
- Update frequency: Real-time (millisecond-level)
- All exchanges support tick-by-tick data via CTP
