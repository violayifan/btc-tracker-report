## BTC 高级监控系统优化

### 新脚本: btc_advanced_monitor_v2.py
创建优化版高级监控脚本，位置: `/root/.openclaw/workspace/btc_advanced_monitor_v2.py`

### 新增功能模块

1. **量价因子分析**
   - 价格趋势（bullish/bearish/neutral）
   - 成交量趋势
   - 量价相关性
   - 信号强度

2. **链上资金情况**
   - 多空比
   - 资金费率
   - 鲸鱼交易活动
   - 数据来源：Coinglass（免费 API 有限制）

3. **市场情绪分析**
   - 综合情绪评分
   - 恐慌贪婪指数
   - 关键因素分析

4. **宏观新闻分析**
   - GDELT API 获取比特币相关新闻
   - 分析整体影响
   - 列出关键事件

5. **X (Twitter) 市场舆情**
   - 正面/负面/中性提及统计
   - 情绪比
   - 热门关键词
   - Nitter 实例（不稳定）

6. **复盘与迭代系统**
   - 记录每次预测
   - 自动复盘预测准确率
   - 根据准确率调整分析权重
   - 持续优化预测模型
