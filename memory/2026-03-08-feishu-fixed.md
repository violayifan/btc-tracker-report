## 技术要点

### 飞书文档创建
- **权限要求**: `docx:document:create`, `docx:document:write`
- **创建工具**: `feishu_doc` with `action=create`
- **写入工具**: `feishu_doc` with `action=write`
- **文档类型**: docx (飞书文档)
- **内容格式**: Markdown → 自动转换为块

### 内容写入策略
- 简化版: 用于飞书文档（避免400错误）
- 完整版: 用于知识库和消息
- 内容块: 自动将Markdown转换为结构化块

### 错误处理
- 文档创建失败: 标记为主会话处理
- 内容写入失败: 使用简化版本重试
- 网络超时: 使用默认值和继续执行

## 已知限制

1. **飞书文档内容限制**
   - 飞书文档写入对内容长度有要求
   - 超长内容可能导致400错误
   - 解决方案: 使用简化版本写入飞书文档

2. **Python版本兼容性**
   - 当前运行 Python 3.6.8
   - `subprocess.run` 的 `capture_output` 和 `text` 参数不可用
   - 解决方案: 使用 `subprocess.Popen` 配合 `universal_newlines=True`

3. **主会话依赖**
   - 飞书文档创建需要主会话处理
   - 脚本标记需要处理的任务
   - 临时文件用于进程间通信
