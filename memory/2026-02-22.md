## BTC 监控系统诊断

### 问题：用户反馈定时任务"不运行"，没有网页更新网址

**实际情况**：
- BTC 市场分析从 04:00 开始每小时运行（04:00, 05:00, 06:00, 07:00, 08:00, 09:00, 10:00, 11:00）
- 系统通过定时提醒（system event）触发，每次运行 `python3 /root/.openclaw/workspace/btc_monitor.py`
- 但没有运行完整的 `update_btc_report.sh` 脚本

**根本原因**：
- HEARTBEAT.md 中手动触发步骤只说明了运行 `btc_monitor.py`
- 没有说明需要运行 `/root/.openclaw/workspace/update_btc_report.sh`

### Cron 定时任务配置

检查结果：cron 任务实际上已经在运行
```bash
# 当前 crontab
0 * * * * /root/.openclaw/workspace/auto_update.sh >> /root/.openclaw/workspace/auto_update.log 2>&1
0 * * * * /root/.openclaw/workspace/update_btc_report.sh >> /root/.openclaw/workspace/update_btc_report.log 2>&1
```

### 两个运行系统

1. **Cron 定时任务**（每小时整点自动运行）
   - 运行 `update_btc_report.sh`
   - 完整流程：
     1. 运行 `btc_monitor.py`（市场分析）
     2. 运行 `btc_html_report_v2.py`（生成 HTML）
     3. 部署到 Netlify

2. **系统提醒**（通过 cron 或其他方式触发）
   - 只运行 `btc_monitor.py`
   - 只做市场分析，不生成 HTML 和部署

### Netlify 部署

**网址**: https://btc-tracker-report.netlify.app

**更新机制**: 
- 网址保持不变
- 内容自动更新（当 cron 任务运行 `update_btc_report.sh` 时）

**部署流程**:
1. 生成 HTML: `/root/.openclaw/workspace/btc_report_enhanced.html`
2. 复制到: `/root/.openclaw/workspace/netlify_deploy/index.html`
3. 使用 Netlify CLI 部署: `netlify deploy --prod --dir=.`

### 文件位置
