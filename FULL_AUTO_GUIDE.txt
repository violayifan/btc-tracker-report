📝 一次性配置步骤（只需一次）：

步骤 1: 创建 GitHub 仓库（5 分钟）
  1. 访问: https://github.com/new
  2. 仓库名: btc-tracker-report
  3. 设为 Public（公开）
  4. 选择 Initialize with README
  5. 点击 Create repository

步骤 2: 在服务器上配置 Git（2 分钟）
  在服务器上运行:

  ```
  cd /root/.openclaw/workspace
  
  # 初始化 Git
  git init
  
  # 创建 .gitignore 文件
  echo "*.txt" > .gitignore
  echo "*.log" >> .gitignore
  echo "*.sh" >> .gitignore
  
  # 添加 HTML 文件
  git add btc_report.html
  
  # 首次提交
  git commit -m "Initial commit: BTC tracker HTML report"
  
  # 添加远程仓库（替换 YOUR_USERNAME）
  git remote add origin https://github.com/YOUR_USERNAME/btc-tracker-report.git
  
  # 推送到 GitHub
  git push -u origin main
  
  # （第一次需要输入 GitHub 用户名和密码，或使用 SSH Key）
  ```

步骤 3: 在 Vercel 中连接此 GitHub 仓库（2 分钟）
  1. 访问: https://vercel.com/signup
  2. 使用 GitHub 登录（免费）
  3. 点击 "Import Project"
  4. 搜索或粘贴您的仓库地址: `https://github.com/YOUR_USERNAME/btc-tracker-report`
  5. 点击 Import
  6. 等待 Vercel 部署完成
  7. Vercel 会显示 URL: `https://btc-tracker-report.vercel.app`

步骤 4: 获取自动部署脚本（已经为您创建了）
  我创建了自动化脚本，在服务器上运行后会：
  - 自动提交新的 HTML 文件到 Git
  - 自动推送到 GitHub
  - Vercel 自动检测到推送并重新部署
  - 几分钟后，用户访问的就是最新的报告

💡 自动化脚本:
  我已经为您创建了 `btc_monitor_auto_deploy.py`，在服务器上运行时会自动执行部署。

🚀 完全自动化的效果:
  • 每小时 BTC 监控运行

  • 自动部署到 Vercel

方案 2: Netlify API 直接上传（需要 API Token）
--------------------------------------------------------------------------------
✅ 优势：
  • 完全自动化（脚本直接执行）
  • 无需 Git 配置
  • 直接获得 URL
  • Netlify 全球 CDN

📝 一次性配置步骤（只需一次）：

步骤 1: 获取 Netlify Personal Access Token（2 分钟）
  1. 访问: https://app.netlify.com/user/applications
  2. 点击 "New access token"
  3. 输入描述: "BTC Tracker Auto Deploy"
  4. 点击 Generate token
  5. **重要：** Token 只显示一次，请复制并保存

步骤 2: 创建 Netlify 站点并获取 Site ID（2 分钟）
  1. 在 Netlify 控制台，点击 "Add new site"
  2. 选择 "Import an existing project"
  3. 选择 "Manual deploy"
  4. 选择 HTML 文件并部署
  5. 部署完成后，在 Site settings 中查找 Site ID
  6. Site ID 格式类似: `abc123-def456-ghi789`

步骤 3: 配置环境变量（1 分钟）
  在服务器上运行:

  ```
  export NETLIFY_TOKEN='你的_TOKEN'
  export NETLIFY_SITE_ID='你的_SITE_ID'
  ```

  或添加到 `~/.bashrc` 或 `~/.profile`:

  ```
  export NETLIFY_TOKEN='你的_TOKEN'
  export NETLIFY_SITE_ID='你的_SITE_ID'
  ```

步骤 4: 运行自动化部署脚本（已创建）
  我已经为您创建了 `auto_deploy_token.py`，在服务器上运行后会:
  - 直接调用 Netlify API 上传 HTML
  - Netlify 返回公网 URL
  - 无需任何手动操作

💡 自动化脚本:
  已经为您创建了自动化脚本，服务器脚本会自动调用 Netlify API 上传并获取公网 URL。

🚀 完全自动化的效果:
  • 每小时 BTC 监控运行
  • 自动生成 HTML 报告
  • 自动通过 API 上传到 Netlify
  • 直接获得公网 URL
  • 无需任何手动操作

  • 国内访问相对稳定

📝 一次性配置步骤（只需一次）：

步骤 1: 注册 Cloudflare 账号（1 分钟）
  1. 访问: https://dash.cloudflare.com/
  2. 注册账号（免费）

步骤 2: 创建 Pages 项目（2 分钟）
  1. 登录 Cloudflare 控制台
  2. 左侧菜单选择 "Workers & Pages"
  3. 点击 "Create application"
  4. 点击 "Pages" -> "Create a project"
  5. 选择 "Upload assets"
  6. 上传 HTML 文件
  7. 点击 "Deploy site"
  8. 等待部署完成，Cloudflare 会显示 URL

步骤 3: 配置自动化（需要 Cloudflare API）
  1. 在 Cloudflare API 中获取 API Token
  2. 创建自动化脚本调用 Cloudflare API
  3. 自动上传 HTML 并部署

💡 自动化脚本:
  需要调用 Cloudflare API，比 Netlify API 更复杂，但也可以完全自动化。
