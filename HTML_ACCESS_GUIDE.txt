📝 最快访问方式（SSH 端口转发）
================================================================================

推荐方式：最简单、免费、安全、无需公网 IP

步骤 1: 在您的电脑上打开终端
  • Windows: 打开 PowerShell
  • Mac: 打开 Terminal
  • Linux: 打开 Terminal

步骤 2: 运行 SSH 端口转发命令
  
  Windows PowerShell:
    ssh -N -L 8081:localhost:8081 root@47.90.150.51
  
  Mac/Linux:
    ssh -N -L 8081:localhost:8081 root@47.90.150.51

  参数说明:
    • -N: 不执行远程命令（只转发端口）
    • -L 8081:localhost:8081: 端口转发
      - 8081: 您本地电脑上的端口
      - localhost: 本地地址
      - 8081: 服务器上的端口
    • root@47.90.150.51: SSH 连接信息

步骤 3: 输入 SSH 密码
  • 系统提示时，输入您的服务器 SSH 密码
  • 如果使用密钥登录，会自动使用

步骤 4: 保持 SSH 终端打开
  • 不要关闭终端窗口
  • 端口转发会一直运行
  • 关闭终端即停止访问

步骤 5: 在浏览器中访问
  • 打开任意浏览器（Chrome, Edge, Safari, Firefox）
  • 在地址栏输入: http://localhost:8081/
  • 回车！

步骤 6: 完成！
  • 您可以看到完整的 HTML BTC 监控报告
  • 包含市场分析、回测图表、统计数据
  • 所有内容都在一个页面，美观显示

💡 提示:
  • 端口转发是临时的：SSH 断开后停止
  • 要停止转发：关闭终端窗口或按 Ctrl+C
  • 如果 8081 端口被占用：改为 8082, 8083 等
  • Windows 可能提示"防火墙已阻止"：点击"允许访问"

❓ 常见问题 (FAQ)
================================================================================

Q: SSH 提示 "端口转发失败"？
A: 检查本地 8081 端口是否被占用
   Windows: netstat -ano | findstr 8081
   Linux/Mac: netstat -tuln | grep 8081
   如果被占用，关闭占用程序或使用其他端口（如 8082）

Q: 无法连接到服务器？
A: 检查:
   • 服务器 IP 是否正确
   • SSH 服务是否运行: sudo systemctl status sshd
   • 防火墙是否允许 SSH（端口 22）

Q: 浏览器显示 "无法访问此网站"？
A: 检查:
   • SSH 连接是否仍保持打开
   • 端口转发是否仍在运行
   • 浏览器地址是否正确: http://localhost:8081/
   • 查看错误信息

Q: 如何停止端口转发？
A: 在 SSH 终端窗口中按 Ctrl+C，或直接关闭窗口

Q: 手机无法连接？
A: 检查:
   • Termius 端口转发是否启用
   • 是否连接到服务器
   • 检查网络连接
   • 尝试重启 Termius 应用
