📝 详细步骤:

1️⃣ 下载 HTML 文件到您的本地电脑:
   ------------------------------------------------
   方式 A: 使用 SCP 命令下载（推荐 Windows 用户）
   
   在您的本地 PowerShell 或 Git Bash 中运行:
   ```
   scp root@47.90.150.51:/root/.openclaw/workspace/btc_report.html ./
   ```
   
   参数说明:
   • root: 服务器用户名
   • 47.90.150.51: 服务器 IP
   • :/root/.openclaw/workspace/btc_report.html: 服务器上的文件路径
   • ./: 下载到当前目录
   
   输入 SSH 密码后，文件会自动下载到您的本地电脑
   
   ------------------------------------------------
   方式 B: 使用 FileZilla 或 WinSCP（推荐初学者）
   
   1. 下载并安装 FileZilla:
      https://filezilla-project.org/download.php
   
   2. 打开 FileZilla
   
   3. 配置连接:
      • 主机: 47.90.150.51
      • 用户名: root
      • 密码: [您的 SSH 密码]
      • 端口: 22
   
   4. 点击"快速连接"
   
   5. 下载文件:
      • 导航到: /root/.openclaw/workspace/
      • 找到: btc_report.html
      • 右键点击 → 下载
      • 选择保存位置并保存
   
   ------------------------------------------------
   方式 C: 如果在本地 WSL 或 Git Bash 中，使用 cp:
   
   ```bash
   # 如果您的 WSL 环境可以访问服务器文件系统
   cp /root/.openclaw/workspace/btc_report.html ./btc_report.html
   ```
   
   💡 提示: 选择最方便您的下载方式

2️⃣ 访问 Netlify 拖拽部署页面:

💡 高级技巧（可选）
================================================================================

1. 自定义域名（更专业）:
   ------------------------------------------------
   • 在 Netlify 项目设置中，点击 "Domain settings"
   • 点击 "Add domain"
   • 您可以:
     • 购买一个新域名
     • 使用您已有的域名
   • 购买免费域名（如 .tk, .ml, .ga 等）
   • 配置 DNS
   
   ------------------------------------------------

2. 更新网站（每小时自动更新）:
   ------------------------------------------------
   
   方式 A: 手动更新（简单）
   • 每小时重新上传新的 HTML 文件
   • 覆盖旧文件
   • Netlify 会自动重新部署
   
   方式 B: 使用 Git（自动化）
   • 创建 GitHub 仓库
   • 将 HTML 文件推送到 GitHub
   • Netlify 连接 GitHub 仓库
   • 每次推送时自动重新部署
   
   ------------------------------------------------

3. 查看部署历史:
   ------------------------------------------------
   • 在 Netlify 项目页面
   • 点击 "Deploys" 标签
   • 可以看到所有部署历史
   • 可以回滚到之前的版本
   
   ------------------------------------------------

4. 使用 Netlify CLI（更高级）:
   ------------------------------------------------
   • 安装 Netlify CLI: npm install -g netlify-cli
   • 在服务器上运行: netlify login
   • 部署: netlify deploy --dir=. --prod
   • 每小时自动运行
   
   ------------------------------------------------

🔧 故障排查
================================================================================

Q: 下载文件时出现错误？
A: 检查:
   • 服务器 IP 是否正确
   • SSH 密码是否正确
   • 网络连接是否稳定
   • 文件路径是否正确

Q: Netlify 上传失败？
A: 检查:
   • 文件是否完整
   • 文件大小是否正常
   • 网络连接是否稳定
   • 浏览器是否支持

Q: 部署一直卡住？
A: 检查:
   • 网络连接是否正常
   • Netlify 服务是否正常
   • 尝试刷新页面或重新上传

Q: 访问 URL 显示 404？
A: 检查:
   • URL 是否正确
   • 网站是否已完全部署
   • 尝试访问 Netlify 项目页面查看状态

Q: 国内访问慢？
A: 解决:
   • 使用 Cloudflare 的 Cloudflare Workers 部署到 Cloudflare Pages
   • 或者使用国内类似的免费托管服务
